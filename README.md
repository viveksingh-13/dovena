# Dovena

> **AI-powered productivity and automation platform**

Dovena is a modern AI platform designed to help individuals and teams work smarter by bringing **AI assistance, intelligent workflows, and automation** into one simple workspace.

The goal of Dovena is to turn repetitive work into automated workflows and make powerful AI capabilities accessible through a clean, intuitive interface.

---

## ✨ Vision

**Dovena = AI + Automation + Productivity**

Instead of switching between multiple tools, Dovena aims to provide a unified platform where users can:

* 🤖 Interact with AI
* ⚡ Automate repetitive tasks
* 🔄 Build intelligent workflows
* 🧠 Use AI to assist with everyday work
* 📊 Manage and monitor automated processes
* 🔌 Connect with external services
* 🚀 Build productivity workflows around their needs

> Dovena is currently under active development.

## ⚡ Getting Started

### Prerequisites

Make sure you have installed:

* Node.js 18+
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/viveksingh-13/dovena.git
```

Move into the project:

```bash
cd dovena
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🎯 Long-Term Goal

Dovena aims to become an **AI-first productivity platform** where users can describe what they want to accomplish and let AI handle the underlying workflow.

For example:

```text
"Every Monday, check my upcoming meetings,
prepare a summary of what I need to prepare,
and send it to me."

                    ↓

                 DOVENA

                    ↓

        AI understands the request

                    ↓

          Creates an automation

                    ↓

       Runs the workflow automatically
```

The long-term vision is to make automation feel as simple as **having a conversation**.
